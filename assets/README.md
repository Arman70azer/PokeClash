Ressources du jeu.

- `maps/` : grands modèles 3D utilisables comme zone entière (une ville, une route).
- `mapobjects/` : modèles 3D d'objets isolés à poser sur une zone (maisons, fontaine, phare...).
- `characters/` : planches de personnages.
- `Font_Poke.png` : planche de la police d'écriture.
- `tilesets/` : tilesets 2D (tileset.png sert au quartier bourgeois ; serene_village n'est plus utilisé).
- les archives .zip d'origine et les modèles .dae sont dans `source_assets/` à la racine du projet, ignoré par Godot.

Voir `CREDITS.md` à la racine pour l'origine de chaque ressource.
